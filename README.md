# 模拟12306车票候补模块（基础版）
## 项目介绍
本项目使用**链式队列（FIFO先进先出）**模拟12306候补购票业务。
旅客无法买到车票时，提交候补订单，系统按提交时间排队；有退票释放余票时，从队头依次分配车票，**先候补、先出票**。

## 数据结构
采用链式队列存储候补订单。
每条订单包含：订单号、旅客姓名、身份证号、所需票数。

## 系统功能
1. **新增候补订单**：将订单加入队列尾部（入队）
2. **余票发放**：输入本次释放余票数量k，从队头依次处理订单。订单满足票数则出票、出队；余票不足则停止分配。
4. **退出程序**

## 开发信息
- 编程语言：C语言
- 数据结构：链式队列
- 编译运行：gcc waitlist.c -o waitlist && ./waitlist
